# 🎓 GradeMate — Student CGPA Calculator

**A simple, responsive web application to calculate GPA and CGPA using subject grade points and credits.**

🔗 **Live Demo:** [Try GradeMate](https://shifana21.github.io/cgpa-calculator/)

💻 **GitHub Repository:** [cgpa-calculator](https://github.com/shifana21/cgpa-calculator)

## ✨ Features

- 📚 Add subjects with names, grade points, and credits.
- ➕ Add or remove subjects dynamically.
- 🧮 Calculate semester GPA using a credit-weighted formula.
- 🎯 Calculate CGPA from all subjects entered.
- 🔄 Select a semester to view its GPA.
- ✅ Validate inputs to prevent invalid grade points and credits.
- 📱 Responsive design for desktop and mobile devices.
- 🎨 Clean, modern interface.

## 📐 Calculation Formula

### GPA

GPA = Σ (Grade Point × Credits) / Σ Credits

### CGPA

CGPA = Σ (All Subject Grade Points × Credits) / Σ (All Subject Credits)

**Example:**

| Subject | Grade Point | Credits |
|---|---:|---:|
| Python | 9 | 4 |
| DBMS | 8 | 3 |
| Mathematics | 10 | 4 |

CGPA = (9 × 4 + 8 × 3 + 10 × 4) / (4 + 3 + 4)

**Result: 9.09**

*Note: Use your college's official grading scale and CGPA rules for accurate academic results.*

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shifana21/cgpa-calculator.git
   ```

2. Open the project folder:

   ```bash
   cd cgpa-calculator
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` using the Live Server extension, or open the file directly in your browser.

No database, backend, or additional package installation is required.
